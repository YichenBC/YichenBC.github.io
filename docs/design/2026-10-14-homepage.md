# Research homepage redesign

The user requested imagegen concepts, delegated visual selection, and authorized implementation. Selected concept A: warm ivory editorial layout, serif display typography, forest-green links, thin dividers, real portrait. Concept B explores a white/blue research studio grid. Both were generated with the built-in imagegen tool. Generated text, dates, figures and placeholder portraits are not factual source material.

## Scope and implementation plan

1. Add a dedicated `home.html` Jekyll layout and `homepage.css`, without loading the legacy theme JavaScript or its global new-tab behavior. Use native anchors and a native disclosure for earlier publications.
2. Store verified publication records in `_data/research.yml`. Preserve every existing publication, author list, education entry, work period and honor. Keep current employer unnamed.
3. Show three header links: Research, About and Scholar. News remains visible below the hero. Keep an obvious Scholar/GitHub/email row. Old section anchors remain usable.
4. Add the verified ATD achievement in News and its publication row: Hugging Face #1 Paper of the day, September 29, 2026. Sources: https://huggingface.co/papers/2609.29233 and https://huggingface.co/papers/date/2026-09-29 . Avoid live vote-count claims.
5. Implement fluid desktop/mobile layouts, visible keyboard focus, adequate contrast, reduced-motion support, a skip link, and no invented controls or counters. Use actual project illustrations when available; never generated scientific figures.
6. Render locally for structural and desktop/mobile browser checks. Verify internal links, disclosure and Scholar destination. Validate the actual GitHub Pages build and live page after deployment. Synchronize source to `/mnt/nfs/gyc/personal-homepage/releases/`.

## Acceptance

The homepage reads as a personal academic site, shows the real photo and verified research, has three useful header destinations, fits a 375px screen without horizontal overflow, and makes full older publications accessible. Metadata provides the correct site identity and share URL. No current company name, private résumé details or generated factual text enters the page.

## Implementation and validation

Implemented the selected direction using a dedicated Liquid layout, data-backed research entries, and plain responsive CSS. No new runtime JavaScript or font service dependencies. Earlier publications and honors use native HTML disclosures. All previous primary publication titles and author lists are retained.

Local Liquid 4.0 rendering succeeded for all ten entries. Browser checks covered desktop and 375px mobile layouts, research navigation, the six-publication disclosure, a single H1, local anchor targets, and no mobile horizontal overflow. The current-employer privacy constraint was retained.

## User feedback: typography and simpler academic presentation

The user found the text too small and the overall page too obviously generated. The next revision replaces the editorial treatment with a straightforward personal academic layout: readable 16–18px prose, 19–20px paper titles, sans-serif headings, a modest square portrait, restrained blue links and shorter section spacing. Decorative eyebrows, section captions, repeated achievement badges and the separate year/category column are removed. The real paper figures, ATD news, authors, URLs, older publications and honors remain. The no-image VenusBench entry becomes a text entry instead of a typeset placeholder.

Core HTML/CSS implementation is delegated through the official Devin CLI to `claude-opus-5-5-high` in an isolated directory. The primary agent reviews the diff, renders the Liquid page, checks desktop and mobile layout, and verifies deployment.

Revision validation: strict Liquid rendering completed with all 10 research entries. Browser checks passed at 1280, 960, 375 and 320px with no horizontal overflow; older publications expand correctly and all local anchors resolve. Numeric venue values are converted to strings before checking for an existing year, preventing the VPEBench date from rendering twice. The typography on mobile is 16px prose, 19px paper titles and 14px author metadata.
